# Контекст проекта safe

Репозиторий заведён владельцем 09.10.2026 пустым; наполняется первой историей
плана 015 (US-0025) из `platform/safe`, экранов Сейфа в `web/` платформы и
решений 0036–0040 платформы.

## Особенности

- Приложение платформы: собирается из опубликованных пакетов `@platform/*` и
  колёс бэкенда, без репозитория платформы (И-3).
- Служба ключей — OpenBao платформы; свой ключ `safe-entries`, вход машинным
  входом приложения.
- На hub — только через приложение `installation` (единица в
  `installation.toml`, выкатка по пушу в `develop`).
- Трейлеры соавторства в коммитах запрещены.
