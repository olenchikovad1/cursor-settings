## Сезон дропа: Докрой или своё? (US-0888)

План предлагал метки профиля (`круглый год` / `сезонный` / `остросезонный`)
читать из Докроя (`docroi_season_label`). В Докрое сейчас — кривые
сезонности продаж (`seasonal_profile`), не каталог меток на дроп.

**Пока сделано:** профиль выводится из окна PLM `intake_week`/`exit_week`
(нет недель — круглый год; ≤12 недель — остросезонный; ≥40 — круглый год;
иначе сезонный). Окно продаж — те же недели. Для локальных дропов стенда —
`release_from`/`release_to`.

**Спросить:** оставить вывод из недель PLM или подключить отдельный справочник
/ API Докроя, когда появится.
