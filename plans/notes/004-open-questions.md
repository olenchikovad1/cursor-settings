# 081 — открытые вопросы владельцу

## US-0554. BOM по релизам фабрики

В старом портале фабрика видела в BOM только строки своих релизов
(`bomReleaseIds`): в Cosmic у ведомости есть релиз. В нашей модели у BOM
ссылки на релиз нет, поэтому сейчас отсечено грубее — фабрика видит BOM
только тех моделей, чьи цветомодели стоят в её релизах, но внутри модели
видит все её ведомости. Чтобы повторить старое, нужна колонка «релиз» у
ведомости и её перенос из Cosmic. Делать?

**Ответ владельца 26.09.2026:** фабрике нельзя видеть чужие BOM. Делаю:
фабрика видит только ведомость, у которой есть строка с цветомоделью её
релиза (правило старого портала; данные для него уже есть, новой колонки не
нужно). Ведомость без привязок фабрике не видна. Сделано: коммит в plm «fix(catalog)».

## US-0581. Уведомления о сообщениях — ждём платформу

Сервис уведомлений платформы шлёт всем обладателям права, а переписке нужна
отправка поимённо: иначе о чате фабрики А узнала бы фабрика Б. Просьба
отправлена сессии платформы 26.09.2026. У нас готово: правило «один сигнал
до прочтения», «без звука», системные строки; сигнал пока пишется в журнал.

## US-0590. PDF техпака — не показан на данных

На стенде нет ни ведомостей, ни табелей, ни картинок: выборка Cosmic их не
привезла. Сборка PDF с таблицами и картинками проверена тестами, но положить
техпак рядом со старым не на чем. Нужна выборка спецификаций из Cosmic на
стенд (это шаг 3 — забрать Cosmic), тогда сверю с живым.

## US-0591. Архив техпака Cosmic — нужен доступ

Скачивание картинки галереи, узла технологии и принта сделано (`b8f3e2b`).
Архив техпака в старом портале шёл через API Cosmic служебной учёткой —
она нам не выдана (`docs/migration/accesses.md`), а медиа Cosmic ещё не
выгружены. Нужно одно из двух: выдать учётку API Cosmic или выгрузить медиа
(шаг 3). На стенде нет ни одной картинки — показать скачивание нечем.

## US-0593. BOM: «место по-русски» и плашка релиза — нет данных

В нашей модели у строки BOM одно поле «место», без русского варианта, а у
ведомости нет релиза (в Cosmic это `bom_subtype`). Место первым, статус
плашкой и «взято из BOM» сделаны (`коммит US-0593`). Для остального нужно
забрать эти два поля из Cosmic при полной выгрузке (шаг 3).

## US-0597. Английский — ждём платформу

Переведено всё своё: отказы сервиса по коду, этапы, условия, причины,
предупреждения карточки, сортировка. Русскими остаются подписи
постраничности таблиц («1–25 из 170», «Строк на странице») и «ВСЕ» в
дереве — они зашиты в `@platform/ui`, запрос платформе отправлен.
Значения справочников (статусы заказа) — данные, их ведут люди.
Склонение чисел не понадобилось: везде «подпись: число».

**Снято 26.09.2026:** платформа перевела подписи (`@platform/ui` 1.65, `@platform/shell` 1.15), пакеты подняты, проверено: «1–25 of 170», «Rows per page». «ВСЕ» — название корневой категории из данных Cosmic, не подпись.

## US-0597 — проверить английский интерфейс глазами (29.09.2026)

Подписи разделов меню уже приходят переводами из `sections.json`, словари
ru/en сверяются тестом. Осталось пройти все разделы на английском в браузере:
встроенный браузер стоит на входе платформы, учётки для проверок нет. Нужно
войти во встроенном браузере — тогда проверю и закрою историю.
