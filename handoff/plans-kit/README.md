# Набор «планы, истории, оценки времени» для Cursor

Папка раскладывается поверх `~/.cursor` (в Windows — `C:\Users\<вы>\.cursor`) и
даёт готовый способ работать с задачами в Cursor: план из пользовательских
историй, размер каждой истории сравнением с эталоном, строка с оценкой перед
каждым шагом и журнал фактов, по которому оценки сами подстраиваются под вашу
машину и модель.

Внутри нет ничего про проекты, машины или планы автора: эталоны обезличены,
стартовый журнал — только числа.

## Что внутри

| Папка | Что это |
|---|---|
| `skills/write-plan/` | как написать план: истории, боль от лица актёра, критерии приёмки, размер по эталону |
| `skills/execute-plan/` | как выполнить план: ветка, история за историей, учёт времени, журнал плана |
| `skills/progress-time-estimates/` | строка «что делаю и сколько займёт» перед каждым шагом |
| `skills/time-estimate-calibration/` | откуда берутся числа: шкала SP, эталоны, версии, журнал |
| `skills/resume-work/` | как продолжить после обрыва чата |
| `hooks/` + `hooks.json` | памятка с эталонами в начале хода, факт хода в журнал, валидатор плана |
| `references/stories/` | 21 эталонная история на 11 осях (`AXES.md` — какая ось что меряет) |
| `references/steps/` | 22 эталонных шага: сколько стоит чтение, правка, тесты, деплой |
| `references/sp-scale.json`, `versions.json` | минуты на размер и версии эталонов |
| `time-analysis/` | `calibrate.py` и хранилище журнала; стартовый журнал — 1700 замеров |
| `plans/_TEMPLATE.md` | шаблон плана |

## Установка

Нужен Python 3.11+ с командой `py` (стандартный установщик Windows). Внешних
зависимостей нет.

Проще всего — отдать папку агенту в Cursor: «прочитай `INSTALL.md` в этой
папке и установи». Там сказано, куда класть каждую папку, как дополнить уже
существующий `hooks.json` и какими командами проверить. Руками — так:

Отдать папку агенту в Cursor и сказать: «прочитай `INSTALL.md` и установи».
Там написано, куда класть каждую папку, как дополнить уже существующий
`hooks.json` и какими командами проверить. Руками — так:

1. Закрыть Cursor.
2. Распаковать архив **поверх** `~/.cursor`. Если `~/.cursor/hooks.json` у вас
   уже есть — не затирать его, а перенести из `hooks.json` набора пять
   записей в свой файл (`sessionStart`, `beforeSubmitPrompt`,
   `afterAgentResponse`, `postToolUse`, `stop`). Остальные папки набора в
   свежем `~/.cursor` ни с чем не пересекаются.
3. Открыть Cursor и проверить в терминале:

```powershell
py -X utf8 ~/.cursor/hooks/tests/test_kit_hooks.py
py -X utf8 -m unittest discover -s ~/.cursor/time-analysis -p "test_*.py"
py -X utf8 ~/.cursor/time-analysis/calibrate.py estimate --sp 3 --compared-to US-9007 "проверка"
```

Первые две команды должны закончиться `OK`; третья — напечатать JSON с
`"minutes"` около 21.

Если в начале нового чата агент получает памятку со строкой эталонов (её видно,
если спросить «что тебе пришло в контексте в начале хода»), хуки работают.

## Как этим пользоваться

- **Есть задача или пачка задач** → попросить агента «составь план» — он
  возьмёт `write-plan`, напишет `plans/001-<направление>-<слаг>.md` с
  историями и размерами по эталонам. Валидатор плана подскажет, чего не
  хватает.
- **«Приступай к плану 1»** → `execute-plan`: ветка, истории по порядку,
  `story-start`/`story-close`, журнал в конце плана.
- **Чат оборвался** → «на чём остановились» → `resume-work`.
- Перед каждым шагом агент пишет строку вроде `Правлю хук и гоняю тесты —
  ~1.5 мин (правки×3, тесты×2)`. Если не пишет, хук напомнит ему в следующем
  ходе.

Скиллы Cursor подхватывает из `~/.cursor/skills/` сам; агенту их не нужно
показывать руками.

## Про числа

Эталоны и стартовый журнал сняты автором набора на модели Opus 5.5 (сентябрь
2026) и считаются у вас **версией 1**. Всё, что меряется на вашей машине,
попадает в **версию 2 «работа в Cursor»** и постепенно перевешивает стартовые
числа — вес растёт с числом ваших замеров, порога нет.

Единица замера в Cursor — **ход целиком**, от вашей реплики до конца ответа:
транскрипт Cursor не хранит времени отдельных вызовов инструментов, и хук
меряет то, что может. Поэтому первые недели ваши замеры будут длиннее
стартовых — это не «стало медленнее», а другая единица. При устойчивом
расхождении хук предложит завести новую версию эталонов; заводится она только
вашим ответом.

Эталонные истории описывают чужие проекты. Когда у вас закроется история на той
же оси и уровне — заменить стартовый эталон своим (`AXES.md`, раздел «Как фонд
поддерживается»).

## Что не входит

- Синхронизация `~/.cursor` между несколькими машинами.
- Реестр проектов: проект — это рабочая копия, открытая в Cursor.
- Предохранители от разрушительных команд и прочие хуки, не связанные с
  планами и временем.
- Команда `calibrate.py units` читает транскрипты Claude Code и в Cursor
  ничего не находит.
