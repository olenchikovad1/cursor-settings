# Команда, которую владелец запускает сам

## Железное правило

**Команда выдаётся готовой к вставке. Собирать её владелец не должен.**

Если бы он хотел собирать команды сам, он бы не звал инструмент. Склейка,
заглушка и «подставь свой хост» — это домашнее задание, выданное тому, кто
попросил помощи.

## Подключение — отдельным блоком

**Склейка вида «подключиться и сразу выполнить» запрещена.** Не из
эстетических соображений: права администратора через такую склейку не
выполняются — пароль спрашивается интерактивно, а интерактивного ввода в ней
нет. Владелец получает строку, которую нельзя скопировать целиком, и выбирает
из неё кусок мышкой.

```bash
ssh -p 2222 -l olenchikov.a 111.88.107.7
```

**Всё, что делается на машине, идёт следующими блоками.** Одним, если команда
одна; несколькими по порядку, если их несколько. Каждый блок копируется
целиком и работает как есть.

```bash
sudo chgrp olenchikov.a /etc/nginx/sites-available/hr-panel
sudo chmod 640 /etc/nginx/sites-available/hr-panel
```

## Заглушек нет

Хост, порт, учётная запись, путь, имя службы — **подставлены значениями**.
Угловых скобок в выданной команде быть не должно.

**Значения берутся из файла доступов на машине автоматически.** Просить
владельца напомнить адрес или порт запрещено: файл читается всегда, и вопрос
про то, что лежит рядом, — это ещё одна остановка работы на человеке.

Заглушка законна ровно в одном случае: значение знает только владелец и никто
больше. Тогда прямо сказано, что именно вписать.

**`~` — тоже заглушка.** В PowerShell она не раскрывается, и команда падает с
`can't open file 'C:\Users\User\.claude\~\.claude\...'`. Путь
пишется целиком: `C:/Users/User/.claude/hooks/x.py`. То же про `$HOME`,
`%USERPROFILE%` и любую переменную окружения: раскроется она или нет, зависит
от того, куда владелец вставит строку, а он вставляет куда удобно.

## Рядом сказано, что команда делает и как выглядит успех

Владелец запускает то, что видит. Не показать ожидаемый вывод — значит
попросить его выполнить непонятное и потом гадать, сработало ли.

```
-rw-r----- 1 root olenchikov.a 1170 Jul 21 10:29 /etc/nginx/sites-available/hr-panel
```

## Проверка

- блоков минимум два: подключение и то, что на машине;
- в командах нет угловых скобок и слов «ваш», «свой», «пароль»;
- в путях нет `~`, `$HOME` и `%USERPROFILE%` — только целиком;
- каждый блок копируется целиком, без выбора части строки мышкой;
- назван ожидаемый вывод.

## Чего не делать

- склеивать подключение с выполнением в одну строку;
- оставлять заглушку там, где значение есть в файле доступов;
- писать путь через `~`, надеясь, что оболочка его раскроет;
- спрашивать у владельца адрес, порт или путь, которые можно прочитать;
- выдавать команду без описания успешного вывода.
